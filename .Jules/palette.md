## 2023-10-25 - Navbar Accessibility Review\n**Learning:** Icon-only buttons without `aria-label` attributes are inaccessible to screen readers, and missing focus states make keyboard navigation difficult. Adding focus-visible rings using existing tailwind classes (`focus:outline-none focus-visible:ring-2 focus-visible:ring-amber-700 rounded-md p-1`) provides immediate, clear visual feedback for keyboard users without disrupting the visual design for mouse users.\n**Action:** Always verify icon-only buttons include `aria-label` and apply explicit `focus-visible` styling using existing design system tokens for interactive elements.
