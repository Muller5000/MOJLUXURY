## 2026-09-25 - Added Accessibility Attributes to Icon-only Buttons
**Learning:** Icon-only buttons frequently lack 'aria-label' and focus indicators in this application's components, making them difficult to use for screen reader and keyboard-only users.
**Action:** When working on navigation components or UI tools that use icon-only buttons, actively check for and add 'aria-label' and 'focus-visible' utility classes to improve accessibility.
